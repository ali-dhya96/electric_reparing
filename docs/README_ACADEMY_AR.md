# ELECTRIC SYSTEM ACADEMY V5

تم استبدال فيديوهات الشرائح بـ 14 مقطعاً من تسجيلَي الشاشة اللذين أرسلهما صاحب المشروع بتاريخ 28 نوفمبر 2026. الفصول المصورة: 9 من 20.

- الفيديو H.264 MP4 مع دعم العرض على Android وWindows والمتصفح.
- ملفات VTT تحمل التوضيح العربي المصاحب؛ لا يوجد تعليق صوتي.
- جميع اللقطات داخل الفصول المصورة مستخرجة من المقاطع.
- حُذف الصوت، واستُبعدت بعض الأجزاء مثل الملاحة الخارجية والإدخال المحتمل لبيانات الحساب؛ حُجبت حقول المبلّغ في مقطع كتابة الحادث وشريط حالة الهاتف. لا يعد ذلك تدقيقاً شاملاً للخصوصية. راجع الأسماء والمواقع وأي بيانات قد تظهر قبل النشر العام.
- التسجيلات لا تغطي كل وظائف النظام (مثل رسم المساح، المحاكاة، التفعيل والتحديث، الحاسبات الإضافية). تلك الفصول مكتوبة فقط.
