# أكاديمية ELECTRIC SYSTEM — تحديث الموقع التعليمي

الحزمة تتضمن مجلد docs كاملاً، بعد تطوير النسخة المرفقة بتاريخ 26 نوفمبر 2026. 20 فصلاً، 20 فيديو MP4 صامتاً (720p، 29–56 ثانية تقريباً لكل درس) مع نص مكتوب وصور توضيحية. أضيفت ستة فصول جديدة وفق ملفات V41–V42.04.3 المتوفرة. لا يُعد الدليل اختباراً فعلياً للوظائف على Windows أو Android.

## نشر الموقع
1. فك الضغط، وافتح مجلد docs داخل الحزمة.
2. ارفع محتوياته إلى مجلد docs في مستودع الموقع الموجود لديك، مع استبدال الملفات المتطابقة وإضافة المجلدات الجديدة.
3. أبقِ config.json المنشور إذا كنت قد غيّرت روابط التنزيل أو أرقام الدعم أو الشبكات الاجتماعية. لم نغير محتواه في الحزمة.
4. لا تغيّر إعداد GitHub Pages إذا كان يعمل بالفعل من main /docs.
5. بعد النشر افتح academy.html أو اضغط «أكاديمية النظام» من الرئيسية. الدليل المكتوب في guide.html. الفيديوهات مضمّنة أيضاً في كل فصل. لا تحتاج SQL أو APK أو تغيير الخادم.

## الصور الفعلية
تم الاحتفاظ بصورة dashboard-real.jpg، وإضافة مقتطف من شريط المبرمج وصورة لوحة المتابعة الخارجية المقدمتين سابقاً. باقي النماذج توضيحية وليست صوراً من تشغيل النظام. الحزمة المرفقة كانت موقع HTML وليست برنامج Flutter قابلاً للتشغيل. لم يتوفر Flutter أو جهاز Android هنا. لإضافة صور أصلية جديدة، التقطها من TEST دون أسماء أو هواتف أو رموز تفعيل أو معلومات مواقع حساسة، وضعها في assets/guide. راجع أسماء الصور القديمة في README_GUIDE_AR.md. الأسماء الجديدة التي يدعمها الاستبدال التلقائي:
- catalog-real.png — إدارة القطاعات أو مكتبة الأصول
- feeder-editor-real.png — محرر Windows
- feeder-view-real.png — عرض المسارات
- feeder-survey-real.png — محرر Android
- feeder-data-real.png — إدارة بيانات الشبكة
- feeder-simulation-real.png — المحاكاة والمخطط

## تحديث الفيديوهات مستقبلاً
الفيديوهات في assets/academy، واسم كل ملف يطابق اسم صفحة guides. يمكن استبدال MP4 وJPG المطابقين بتسجيل شاشة حقيقي بعد إخفاء المعلومات الحساسة، من دون تغيير الروابط. عدّل وصف الفيديو في الصفحة بعد استبداله لتوضيح أنه تسجيل فعلي. يمكن تعديل النص المكتوب مباشرة في guides/*.html. صفحة academy.html تجمع جميع الدروس.

## الاختبار
تحققنا من وجود الملفات المرتبطة محلياً، وصحة بناء JavaScript، وتوليد الفيديوهات بصيغة H.264، ومعاينة شرائح مختارة. لم ينجح اختبار المتصفح الحي بسبب قيود بيئة التشغيل، ولم يُنشر الموقع فعلياً على GitHub. اختبر صفحة التحميل والدليل والفيديوهات على هاتف وحاسوب بعد النشر. صور الخرائط والمخططات التوضيحية ليست معتمدة هندسياً ولا تدل على حالة التيار.
