# موقع ELECTRIC SYSTEM V2

هذه ملفات موقع GitHub Pages. انشر الملفات في مسار `electric_reparing/docs/` مع تفعيل Pages من `main /docs`.
عدّل `config.json` لإضافة واتساب وروابط إنستغرام وفيسبوك وتيليغرام ويوتيوب.
لتحديث أزرار تحميل Windows وAndroid وiOS، انشر التحديث الخاص بدالة Supabase `electric-public-downloads` من الحزمة الكاملة.
لا ترفع مفاتيح Supabase السرية أو ملفات Flutter إلى مجلد `docs`.
