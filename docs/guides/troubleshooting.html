01 / الشرح التفصيلي

الحاسبة الإضافية تحمل ثم تغلق

إذا اختفت نافذة Windows بالكامل فهذه مشكلة انهيار تشغيل، تختلف عن رفض صلاحية الحساب. افتح سجل Windows: Event Viewer ← Windows Logs ← Application، وابحث عن Application Error قرب وقت الانهيار.

ورد في سجل جهاز سابق خطأ 0xc0000005 داخل MSVCP140.dll؛ قد يرتبط بمكتبات Visual C++ أو إضافة أصلية، ولا يثبت وحده تلف DLL. أصلح حزمة Microsoft Visual C++ الرسمية واستخدم مثبت البرنامج الكامل قبل تعديل قاعدة البيانات.

02 / الشرح التفصيلي

المجاميع لا تظهر

  1. تحقق أنك دخلت بحساب المركز المقصود.
  2. راجع صلاحية «عرض المجاميع» للحاسبة الإضافية.
  3. تحقق من وجود مجموعة محفوظة في Supabase تحت معرّف مركزك.
  4. حدّث القائمة بعد الاتصال.
  5. إذا ظهرت مجموعات على الهاتف دون الكمبيوتر، يجب فحص اختلاف tenant_id ومصدر البيانات.
03 / الشرح التفصيلي

المخول يظهر «غير معروف»

لا تحذف حساب المخول. افحص خدمة الحضور الفعلية، نسخة Windows، نبضات Android، معرّف المخول وصلاحيات القراءة. عدم وجود نبضات حديثة يعني عدم وجود تأكيد «متصل»، وليس دليلاً على فشل الحساب نفسه.

04 / الشرح التفصيلي

المحولة تظهر بموقع خاطئ

  1. قارن الرقم مع اسم المحطة والمغذي ومعرّف المحولة الفريد.
  2. تحقق هل الإحداثيات تخص المحولة أو محطة رئيسية قريبة.
  3. افحص مصدر الإحداثيات في البيانات الرسمية، لا العلامة المرئية فقط.
  4. أوقف الملاحة إلى الموقع المشكوك به واطلب تحققاً ميدانياً.
  5. لا تنسخ إحداثيات محولة من مركز آخر لمجرد تشابه الرقم والاسم.
تصحيح GPS إجراء حساس
لا تنفذ أي ملف SQL يغيّر إحداثيات محولة دون تحديد معرّف المحولة ومركز الصيانة ومراجعة الموقع ميدانياً.
05 / الشرح التفصيلي

Android يتوقف بعد 100% تحميل

قد يعني فشل استدعاء مثبّت APK الأصلي، أو أذونات تثبيت غير كافية، أو اختلاف توقيع التطبيق. إذا كانت الرسالة MissingPluginException لـ installApk، فالمعالجة في MainActivity وقناة التثبيت ضمن نسخة APK الجديدة، وليس في رابط البوابة.

06 / الشرح التفصيلي

Windows يعرض CERTIFICATE_VERIFY_FAILED

يعني تعذر التحقق من شهادة HTTPS في اتصال البرنامج. افحص التاريخ والوقت والشبكة وسلسلة الشهادة وبرامج فحص HTTPS. يمكن استعمال متصفح حديث لتنزيل الرابط الرسمي، لكن لا تعطّل التحقق من الشهادات في البرنامج.

07 / الشرح التفصيلي

ظهرت شاشة خطأ JSON عند التشغيل

الخطأ FormatException: Unexpected character يشير عادة إلى بيانات متوقعة كـJSON لكنها غير صالحة. إذا ظهرت مرحلة فحص جلسة Windows المخزنة، فقد يحتاج الإصلاح إلى عزل تفضيلات محلية تالفة مع نسخة احتياطية. لا تحذف مجلد AppData أو أكواد التفعيل دون معرفة أثر ذلك.

08 / الشرح التفصيلي

متى أتواصل مع الدعم؟

  • إذا فشل التحديث رغم صحة رابط التثبيت والتوقيع.
  • إذا ظهرت بيانات مركز آخر في حسابك.
  • إذا لم تصل الحوادث إلى مخولي مجموعة معينة رغم حفظها.
  • إذا تغيّرت إحداثيات محولة أو ظهرت ملاحة خاطئة.
  • إذا تكررت الأخطاء بعد تحديث النسخة المصرّح بها.

للدعم، افتح صفحة الخدمات واختر نوع الطلب. احذف كلمات المرور والأكواد الحساسة من صور الأخطاء قبل مشاركتها.

شروحات بصرية

الصور والأمثلة

صور الشرح التوضيحية مبنية على أسماء وأزرار من ملفات المشروع، وليست لقطات تشغيل فعلية. الصورة المعلَّمة «لقطة فعلية» مصدرها صورة سابقة أرسلها صاحب النظام. عند تزويد لقطات Windows وAndroid الأصلية يمكن استبدال النماذج دون تغيير الشرح.

خلصت هذا الفصل؟

تقدر ترجع للفهرس أو تنتقل إلى الفصل التالي. إذا كان المطلوب يخص جهازك الفعلي، راجع صلاحية الحساب والإصدار المثبّت قبل تنفيذ أي خطوة.
