01 / الشرح التفصيلي

ما الذي يظهر في التقارير؟

تعرض شاشة «التقارير والإحصائيات» أرشيف الحوادث وتحليلاتها، مع حالات الإنجاز والتعذر، وتوزيع أنواع الأعطال ومؤشرات أداء المخولين بحسب البيانات المتاحة.

هدف الأرشيف هو معرفة ما حدث، وليس تعديل محولة أو إعادتها إلى موقع آخر.

03 / الشرح التفصيلي

كيف أقرأ تقرير حادث منجز؟

  1. حدد الفترة المناسبة.
  2. ابحث عن رقم المحولة أو المحطة أو بطاقة الحادث.
  3. راجع وقت إنشاء الحادث ووقت استلامه ووقت إنجازه.
  4. اقرأ تقرير العمل المنجز، وليس الحالة فقط.
  5. إذا وجدت بيانات ناقصة تحقق من سجل الحادث والمزامنة مع الخادم.
04 / الشرح التفصيلي

كيف أقرأ تقرير تعذر الإنجاز؟

حالة «غير منجز» أو «تعذر» تتضمن سبباً يُكتب أثناء إنهاء المهمة. تعلّم الفرق بين أسباب التشغيل (نقص مواد، وصول غير ممكن، خلل يحتاج إسناداً) وبين مشكلات الاتصال التقنية التي لا ينبغي تسجيلها بوصفها تعذر صيانة دون تحقق.

05 / الشرح التفصيلي

تصدير PDF

  1. افتح شاشة التقارير.
  2. حدد «الكل» أو «يومي» أو «فترة».
  3. اضغط «تصدير PDF».
  4. راجع عنوان التقرير والتاريخ والأسماء قبل مشاركة الملف.
  5. احفظ التقرير في موقع مناسب لا يمكن للجميع الوصول إليه إذا احتوى بيانات تشغيلية أو أرقاماً شخصية.
بيانات التقرير ليست منشوراً عاماً
لا ترفع تقارير الحوادث الحقيقية أو أرقام هواتف المبلغين إلى صفحة GitHub العامة.
06 / الشرح التفصيلي

الفرق بين الإخفاء والحذف

بعض شاشات الحوادث توفر «تفريغ الشاشة» للحوادث المنتهية دون حذف التقرير؛ أما «حذف نهائي» من الأرشيف، إن أتاحه الدور، فهو إجراء مختلف وله تبعات. تأكد من تسمية الزر والرسالة التحذيرية قبل التأكيد.
