# ELECTRIC SYSTEM ACADEMY — V6

نسخة موقع V5 مع إضافة مختبر تدريبي مستقل، يغطي الفصول العشرين في 74 خطوة، منها أسئلة وتمارين نماذج ورسم تفاعلي على خريطة تخطيطية وتصدير/فحص JSON تدريبي. لا يتصل المختبر بقاعدة البيانات أو يستدعي GPS الجهاز ولا يحوي بيانات دخول حقيقية. بعض العمليات ممثلة بتمرين اختيار أو نموذج مبسط؛ ليست نسخة Flutter أو بديلها التشغيلي.

## النشر
1. فك الأرشيف وانسخ محتويات مجلد docs إلى docs في المستودع الحالي.
2. احتفظ بملف config.json المنشور لديك إذا كان مختلفاً؛ لم تتغير إعدادات التحميل أو الدعم.
3. افتح simulator.html أو اختر «المختبر التعليمي» من الرئيسية أو الدليل أو مكتبة الفيديوهات. كل فصل يحتوي رابطاً للتمرين الخاص به.
4. يختار المختبر شكل Windows أو Android بحسب الدرس، ويمكن تغييره يدوياً. تصميم الموقع نفسه متجاوب، والقائمة الجانبية للتدريب تُستبدل بقائمة اختيار على الهاتف. التقدم وحالة التدريب في الذاكرة فقط؛ إعادة تحميل الصفحة تعيد النموذج.
5. احتفظنا بالفيديوهات والصور الأصلية في V5. راجعها قبل النشر العام لوجود احتمال ظهور أسماء أو بيانات مواقع أو معلومات تشغيلية. لم نضف تسجيلات اصطناعية على أنها تصوير فعلي.

## الاختبار
- فحص JavaScript بواسطة Node.
- تشغيل HTML/CSS/JS للمختبر داخل Chromium محلياً بإدراج محتوى الصفحة، وإكمال 74 خطوة عبر 20 درساً باستخدام الأزرار والحقول والنقر على الخريطة، بما في ذلك تنزيل JSON وإعادة فحصه. لم تظهر أخطاء JavaScript في هذا الاختبار.
- معاينة شكل المختبر عند عرض الحاسوب والهاتف. تعذر التنقل المباشر إلى ملفات الموقع أو خادم محلي بسبب قيود المتصفح، لذلك لا يوجد اختبار نشر فعلي أو تشغيل فيديو عبر المتصفح. فحص تجاوب بقية الموقع محدود، وليس اختباراً شاملاً على أجهزة حقيقية.
- لا يلزم تعديل Supabase أو Flutter. التغييرات تخص الموقع فقط.
